Use `npx prismic` for everything it can do. Read `npx prismic --help` before your first command. Create, update, and publish content with the Prismic MCP server, sample content included. Don't use the Migration API or a write token unless the user asks. If the MCP server isn't connected, ask the user to connect it (`npx prismic docs view mcp`). To move a site, follow `npx prismic docs view migration`.
